# Quiz App Frontend

React application for the Quiz App, built with Vite and TypeScript.

## Features

- **User Interface**: Clean and responsive UI using Material UI.
- **State Management**: Redux Toolkit for managing user session and quiz state.
- **Routing**: React Router for navigation.
- **Authentication**: Secure login and registration forms.

## Getting Started

### Prerequisites

- Node.js
- Backend server running on port 3555 (default)

### Installation

```bash
npm install
```

### Development

Start the development server:

```bash
npm run start-dev
```

The app will be available at `http://localhost:5173`.

### Build

Build for production:

```bash
npm run build
```

### Linting

Run ESLint:

```bash
npm run lint
```
